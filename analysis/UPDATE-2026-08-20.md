## 3. 主要新功能（按领域）

### 3.1 Web UI / 客户端

- **启动行为：** `dsh web` / `npx @deepseek-ai/dsh web` 本机启动时默认自动打开浏览器；SSH 场景只打印 URL；可用 `--no-open` 关闭自动打开。
- **文件与会话引用：** 输入框支持 `@file` 语法引用文件/目录，以及会话引用（`packages/context/file-reference*`、`packages/client/ui-reference`）。
- **附件与图片：** 斜杠命令路由支持 composer 图片附件（`packages/client/ui-attachment`、`packages/attachment/attachment`）。
- **模型选择：** 模型选择器支持批量选择；默认模型重试次数改为 5 次。
- **插件加载：** Web UI 显示插件加载进度。
- **Ask User：** 问题卡片可折叠/展开。
- **反馈：** 反馈备注改为 popover 浮层，不再挤占操作行。
- **品牌定制：** 客户端通过 slot 组合部署品牌（`packages/client/ui-brand-official`）；新增 `build:official` 构建 profile。
- **路径显示：** POSIX home 路径缩写（`~/...`）。

### 3.2 Agent / Subagent / Teams

- **Agent Teams（实验性）：** 新增 `@deepseek-ai/dsh-experimental-agent-team`，提供持久 roster、任务 DAG、peer mailbox（`ctx.agentTeams`）。详见 `docs/subsystems/agent-team.md`。
- **产品 Subagent：** 支持命名 Claude Code / Codex provider 实例；改进 subagent 失败事实与进程 settlement。
- **Workflow：** 用户可控制 run 与 phase 的披露粒度。

### 3.3 LLM / 模型能力

- **多模态：** DeepSeek 原生 provider 支持 multimodal 请求（`feat(llm-deepseek): support multimodal requests`）。
- **Reasoning 修复：** 每轮 reasoned turn 都会回传 reasoning content，修复思考模式下内容丢失问题（与 `scratch-plugin` 评测场景相关）。
- **Pi AI 配置：** 暴露并收紧 compat 字段校验。

### 3.4 Shell / 终端

- **持久 PowerShell PTY：** 新增 `@deepseek-ai/dsh-tool-pwsh-persistent`，CLI 已引入依赖。
- **持久 Bash：** 改进 controlled prompt，加快 settlement。

### 3.5 Session / 持久化

- **SQLite 布局优化：** Session 持久化采用 chunk packing 新布局（`packages/session/session-persistence-sqlite` 大幅扩展）。**注意：** 项目仍处于开发者预览，不承诺旧格式兼容。

### 3.6 Python SDK / Code Runtime

- **Python SDK 标准 Agent Runtime：** 标准化 Python agent 运行时协议（`packages/code-runtime/code-runtime-python`）。
- **Python 运行时 smoke 测试** 显著扩充。

### 3.7 构建 / 发布 / 基础设施

- **统一构建入口：** `pnpm run build` 改为 `tsx scripts/build.ts`；新增 `build:official` profile。
- **客户端包校验：** 新增 `verify-client-packages`、`verify-optional-dependency-imports` 等 gate。
- **覆盖率分区：** 新增 `test:coverage:partitioned`、`test:web:ci`。
- **README 资源 CDN 化：** 社区二维码等资源改为 `cdn.deepseek.com` 托管。
- **品牌指南拆分：** `BRAND_GUIDELINES.md` 拆为中英双语对。

## 4. 与你本地工作的关系

### 4.1 `scratch-plugin`（办公评测插件）

插件使用的 API（`commands`、`llm`、`agents`、`session`）仍在核心 spine 上，**理论上无需改代码**。但以下上游变化值得关注：

| 变化 | 影响 |
|---|---|
| reasoning content 回传修复 | 若基座模型开思考模式，评测 JSON 解析成功率应提高 |
| SQLite 持久化布局变更 | 旧 session 文件可能无法直接读取（预览期预期行为） |
| 构建流程变更 | 首次更新后需重新 `pnpm run build` |

**推荐启动方式（不变）：**

```sh
pnpm run build          # 首次更新后执行
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

### 4.2 `npx @deepseek-ai/dsh web`

npm 已发布 **0.1.0-rc.8**，`npx` 方式现在应能正常工作（需 Node.js ^22.19 或 ≥24）。
在**源码 checkout** 内仍优先用 `pnpm dsh web`，它走 tsx 源码启动或已构建产物，不依赖全局安装。

## 5. 破坏性 / 迁移提示

项目 README 仍声明 **开发者预览，会有破坏性变更**。本次跨度内 notable 变化：

1. **Session SQLite 格式** — 不保证 rc.5 时期 session 可直接加载。
2. **构建命令** — `pnpm run build` 入口改为 `scripts/build.ts`；官方品牌构建用 `pnpm run build:official`。
3. **实验性包命名** — Agent Teams 相关包迁至 `packages/experimental/`，服务 key 有 rename。
4. **客户端 externals 声明** — browser-only 依赖声明规则收紧，影响插件/客户端包作者。
