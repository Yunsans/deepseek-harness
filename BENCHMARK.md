# Running benchmarks

Follow [Get started with the Python SDK](docs/user/guide/python-sdk.md) to install the SDK and run the `jsonrpc-agent` minimal variant. Use separate workspaces and session IDs for independent benchmark tasks.

To evaluate this repository's agent on τ²-bench (shared Environment + Python SDK adapter), follow [eval/tau2/README.md](eval/tau2/README.md). Architecture notes are in [eval/tau2/plan.md](eval/tau2/plan.md).
